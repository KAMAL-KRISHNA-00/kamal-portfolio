# Kamal Krishna — Portfolio

**The Crimson Edge** — an interactive portfolio built with React, Vite, Framer Motion and Three.js.
A procedural 3D katana cuts between sections as you scroll; the hero mark is a live particle sphere.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
```

Deployed on Vercel.
